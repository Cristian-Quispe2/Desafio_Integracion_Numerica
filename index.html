Integración numérica aplicada a La Paz, Bolivia

Aplicación interactiva para los ejercicios 19–27. Los datos se pueden editar; los escenarios de La Paz son ejemplos didácticos y no mediciones oficiales.

Ejercicios

Selecciona un ejercicio y luego la versión original o la adaptación didáctica a La Paz.

Métodos disponibles: trapecio compuesto, Simpson 1/3 y Simpson 3/8. La aplicación valida los requisitos de cada método.

Ejercicio

Edita, agrega o elimina filas. Las abscisas deben estar igualmente espaciadas para aplicar Simpson o el trapecio compuesto.

Usa x, números, + − * / ^, paréntesis y funciones Math como sin(x), cos(x), sqrt(x), exp(x), log(x), abs(x), sinh(x), cosh(x), pi. No escribas el signo "=".
